does not reopen the Evidence-Carrying Work Loop architecture and adds no product
feature.

- Normal and administrative facade preflights consume that parsed invocation.
- Canonical execution consumes the same parsed invocation without reparsing.

  repository-wide no-mutation contract.

inspection were not changed except for the shared CLI execution boundary needed
