## Generic upgrade

- Public `block-for-source-fix` releases a live task as
  `BLOCKED_SOURCE_FIX` without misclassifying it as an abort.
- Public `continue-task` creates a fresh task with immutable exact lineage to
  a released source. It never reopens historical state.
- Admin-only `adopt-existing-change` records a clean current HEAD as
  `EXTERNAL_PREEXISTING` and then uses normal validation/close assurance.
- The optional side-effect contract centralizes state dimensions, authority
  predicates, retry/replay consumers, crash recovery and schema compatibility.
- Retry and replay paths must reference the same canonical no-effect predicate;
  unknown effect state remains a queue barrier.
