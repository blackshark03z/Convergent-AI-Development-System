## RC1 correction

RC1 passed its mechanical package suite but was not promoted. Final inspection
found that its CLI `inspect` path appended a telemetry control action. RC2 skips
that finalizer for `inspect` and adds a command-surface regression test that
hashes and timestamps every repository file before and after inspection.

RC2 also rejects `REPO_FILE` grounding locators below `.buildos`, preventing
generated lifecycle/control bytes from being presented as independent product
repository evidence.

The final review additionally required exact trusted-launcher Contract binding,
semantic replay of compact action rights from immutable evidence, pre-action
scope adaptation, exact-file repository dependencies, and absolute repository
targets. Packaging now reads all non-generated members from one clean Git HEAD,
uses an explicit manifest allowlist, rejects Windows archive aliases, verifies
before no-replace publication, requires the package source to descend from the
frozen kernel, and emits a final ZIP-hash receipt. The final ZIP plus its
external receipt are the sole RC2 package evidence; stale root-level RC1
generated validation/checksum files were removed. Release JSON is strict,
skipped-test identities are exact, and the bounded credential-pattern scan
covers hyphenated provider token families without claiming a complete secret
scanner.
