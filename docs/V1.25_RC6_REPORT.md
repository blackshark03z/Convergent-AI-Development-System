## Candidate delta

RC6 repairs exactly the three blockers reported by the independent RC5 R3
review. A BLOCKED Goal now requires a schema-valid, repository/commit/tree/Goal
bound OWNER terminal-disposition authorization whose canonical SHA-256 is
pinned by the trusted launcher. The arbitrary authorization-reference path is
retained only as a typed refusal.

A completed transition is now independently verifiable from Git-tracked
archive, inventory, receipt, authorization and replacement evidence in a fresh
clone. Private quarantine remains mandatory while a transition is incomplete,
but is no longer a permanent hidden dependency after the complete evidence set
has been committed.

Legacy executors are now identified by supported canonical paths plus strong
legacy signatures. Legitimate product files that merely share `ai.py` or
`ai_os.py` basenames are preserved byte-identically; ambiguous canonical or
renamed legacy candidates fail closed without mutation.
