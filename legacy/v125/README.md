# Historical v1.25 evidence

This directory preserves the disconnected v1.25 lifecycle implementation,
adoption assets, documentation, packaging scripts and retired tests as
historical evidence.

Nothing here is imported by the simplified public CLI or included in the
simplified portable candidate. It is not active task authority and must not be
used to bootstrap, adopt, continue or migrate current work.

The only supported compatibility path is the read-only legacy effect detector
in `buildos/legacy_effects.py`, because an unresolved external provider action
may still require reconciliation.
